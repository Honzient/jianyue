# 0.2.0 简阅与 Legado 书源模型

| 日期 | versionCode | 包名 |
| --- | --- | --- |
| 2026-11-24 | 200 | `dev.yuejian.reader` |

## 变更

- 项目更名为简阅，WSL2 工程迁入 `~/projects/jianyue`。
- 书源采用 Legado 3.0 的 JSON 字段结构，保留原始文档与扩展字段。
- 批量导入提高至每个文件 16 MB、最多 6000 条，并修复异步分块读取时文件提前关闭的问题。
- 增加表单 POST、GBK 搜索参数、基础 JSONPath 和声明式链接模板。

## 数据与升级

数据库升级到版本 2。旧 `sources` 表中的原书源和实际启停状态迁入 `book_sources`。覆盖安装继续使用原包名。

## 验收

- 在模拟器用一份 348 条 Legado 导出实测全量入库，格式错误 0 条。重复导入更新 348 条、新增 0 条。
- 确认旧书架及停用状态可迁移。测试站走通 POST、GBK、JSONPath 和四个书源阶段。
- 真机验收覆盖签名校验、USB 覆盖安装和安装版本核对。
