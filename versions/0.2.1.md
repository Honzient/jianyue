# 0.2.1 书源查找与项目交接

| 日期 | versionCode | 包名 |
| --- | --- | --- |
| 2026-11-24 | 201 | `dev.yuejian.reader` |

## 变更

- 书源页支持按名称、分组和网址查找，并提供全部、可搜索和待检查三种筛选。
- 导入结果保留计数和错误项，书源列表从数据库加载。重新导入同一书源后，测试页读取最新配置。
- 补齐[交接验收](../docs/HANDOFF.md)、[开发调试](../docs/DEVELOPMENT.md)、[应用架构](../docs/ARCHITECTURE.md)与[书源格式](../docs/BOOK_SOURCES.md)文档。

## 数据与升级

继续使用数据库版本 2。书源查找和筛选在本机已加载的记录上完成。0.2.0 的数据随覆盖安装继续可用。

## 验收

- WSL2 使用 Hvigor 完成 ArkTS 构建，Mate 90 Pro 模拟器安装并启动 0.2.1。
- 在模拟器核对旧书架续读入口，以及名称、分组、网址、状态筛选和无匹配结果提示。
- 更新同一书源后，测试页显示更新后的检查关键词。重复导入 348 条书源时，更新 348 条、新增 0 条、格式错误 0 条。
