# 0.4.0 书源规则与诊断

| 构建日期 | versionCode | 包名 |
| --- | --- | --- |
| 2026-11-25 | 400 | `dev.yuejian.reader` |

## 变更

- 补充旧式 HTML 节点索引、包含和排除区间、常见 CSS 条件及基础 XPath。自动补全省略的表格主体。
- JSONPath 支持递归属性、数组切片、并列下标和简单条件。规则支持组合、书籍变量、地址模板和文本清理。
- 支持带页码偏移的搜索请求模板和 JSON POST。详情、目录和正文可以接收附带请求选项的链接。
- 书源诊断分别显示搜索、详情、目录和正文的规则状态。已配置的书源可继续做联网测试。书源列表区分导入数、有搜索配置的条目和可执行数。

## 数据与升级

数据库升级到版本 3，在 `books` 中增加书籍变量。Legado 3.0 JSON 仍按原字段保存，已有书籍使用空变量初始化。

## 验收

- 在模拟器对同一份 348 条记录的文件离线复查。50 条包含搜索配置，搜索规则可执行数从 19 增至 36，搜索、详情、目录和正文所需规则均可执行的从 5 增至 31。
- 合成样本通过 HTML、XPath、JSONPath、GB18030、JSON POST、携带表单 POST 的阅读链接、变量隔离和书籍存储检查。
- 使用《遮天》实测，「影书小说」和「去读书啊」分别返回 50 条结果并包含同名书。「笔 趣 楼」提取到 0 条结果，「爱读书」站点返回 HTTP 403。
- 模拟器从 0.3.0 覆盖升级，原书源可访问。华为平板覆盖升级到 0.4.0，原有 50 条书源中显示 36 条参与搜索。用「去读书啊」复测《遮天》，搜索、详情、目录和正文均通过。
